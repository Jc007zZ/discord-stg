## Configuration

**Environment Variables (Critical):**
- `DISCORD_CLIENT_ID` - OAuth client ID for Discord Activity
- `DISCORD_CLIENT_SECRET` - OAuth secret (never leaves server, `server/tokens.js`)
- `DISCORD_BOT_TOKEN` - Bot token for guild/voice state queries in `server/index.js` lines 386-450
- `DISCORD_ADMIN_ID` - Comma-separated Discord user IDs for admin panel access
- `SESSION_SECRET` - HMAC key for token signing (`server/tokens.js`), minimum 32 chars in production, generated by `npm run configurar`
- `PUBLIC_ORIGIN` - Public URL of the service (default: `http://localhost:3001`)
- `PORT` - HTTP listen port (default: 3001)
- `NODE_ENV` - Environment (production enables strict checks: SESSION_SECRET required, P2P_ONLY disabled)
- `P2P_ONLY` - Force WebRTC-only mode, disables relay fallback (off by default, staging/testing only)
- `TURN_URL` - TURN server URL for NAT traversal (`server/index.js` line 791-805)
- `TURN_USER` - TURN server username (optional)
- `TURN_PASS` - TURN server password (optional)

**Build Configuration:**
- `.prettierrc.json` - Single quotes, 100 char line width, LF line endings
- `eslint.config.js` - Workspace-wide linting with separate Node and Browser rules
- `vitest.config.js` - Coverage thresholds (86% for lines/statements/functions/branches), test environment is `node` by default with `jsdom` for browser tests

## Platform Requirements

**Development:**
- Node.js 22 LTS or compatible
- npm 9+
- Browser: Chrome, Edge, Brave, or Opera (for screen capture via `getDisplayMedia`)
- Cloudflare account (optional, for persistent tunnel via `npm run tunel:criar`)

**Production:**
- Deployed on Square Cloud (`squarecloud.app` config file)
- Docker container (Node 22 slim base, multi-stage build in `Dockerfile`)
- Environment: Must set `NODE_ENV=production`, `SESSION_SECRET`, and Discord credentials
- Memory: 512 MB minimum (as per `squarecloud.app`)
- Port: 80 on Square Cloud, 3001 locally/in container

## Deployment Pipeline

**Build Steps:**
1. npm ci (install exact versions from package-lock.json)
2. npm run build (vite build for client)
3. Runtime: npm start (build + server startup, as configured in `squarecloud.app`)

**Docker Deployment:**
- Two-stage build: compile stage (includes vite, devDependencies), runtime stage (only production code)
- Health check: `GET /api/health` must return 200 OK
- User: node (non-root, built-in to official Node image)
- Exposed port: 3001

**Source Control:**
- `client/dist/` is `.gitignore`d and built at deploy time
- `node_modules/` is `.gitignore`d
- `coverage/` is `.gitignore`d
- Cloudflare configuration from `npm run tunel:criar` persists in `.env`
